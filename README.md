# Excel Loader · TARGET.xlsx

Локальное веб-приложение для загрузки и обновления данных в Excel.

## Быстрый старт (Windows)

1. Установите [Python 3.11 или 3.12](https://www.python.org/downloads/) (галочка **Add to PATH**).
2. Дважды нажмите `start.bat`.
3. Откроется браузер: [http://127.0.0.1:8766](http://127.0.0.1:8766).
4. Нажмите **Открыть Excel** и выберите `.xlsx` в проводнике.

Если `pip install` падает: удалите папку `.venv` и запустите `start.bat` снова.
Нужен Python **3.11 или 3.12** (не Microsoft Store / не слишком новый 3.14).

Linux / macOS: `chmod +x start.sh && ./start.sh`

## Что умеет

- Выбор рабочего Excel через проводник (**Открыть Excel**)
- Просмотр листов и превью строк
- Загрузка источника данных (`.xlsx` / `.csv`)
- Автосопоставление колонок + ручная правка
- Режимы записи:
  - **Обновить / добавить (upsert)** — по ключевым колонкам
  - **Добавить строки (append)**
  - **Заменить данные листа (replace)** — очищает строки под заголовком
- **Создание нового листа** (пустой с колонками или из загруженного файла)
- Автобэкап в `backups/` перед каждой записью
- Скачивание обновлённого Excel
- Восстановление из бэкапа

По умолчанию, если ничего не выбрано, используется `TARGET.xlsx` (если он есть в папке).

## Типичный сценарий

1. **Открыть Excel** → выбрать файл в проводнике.
2. Слева выберите целевой лист.
3. Загрузите Excel/CSV с новыми данными.
4. Проверьте маппинг колонок.
5. Для upsert отметьте ключевые колонки.
6. Нажмите **Применить загрузку**, затем **Скачать**.

## Структура

```
TARGET.xlsx          # файл по умолчанию (опционально)
start.bat            # запуск на Windows
start.sh             # запуск на Linux/macOS
requirements.txt
app/
  main.py            # FastAPI
  excel_service.py   # логика Excel
  static/            # UI
data/                # текущий выбранный workbook
backups/             # копии перед записью
uploads/             # временные загрузки
```
