# Excel Loader · TARGET.xlsx

Локальное веб-приложение для загрузки и обновления данных в `TARGET.xlsx`.

## Быстрый старт (Windows)

1. Установите [Python 3.10+](https://www.python.org/downloads/) (галочка **Add to PATH**).
2. Дважды нажмите `start.bat`.
3. Откроется браузер: [http://127.0.0.1:8765](http://127.0.0.1:8765).

Linux / macOS: `chmod +x start.sh && ./start.sh`

## Что умеет

- Просмотр всех листов `TARGET.xlsx` и превью строк
- Загрузка источника (`.xlsx` / `.csv`)
- Автосопоставление колонок + ручная правка
- Режимы записи:
  - **Обновить / добавить (upsert)** — по ключевым колонкам
  - **Добавить строки (append)**
  - **Заменить данные листа (replace)** — очищает строки под заголовком
- **Создание нового листа** в `TARGET.xlsx` (пустой с колонками или из загруженного файла)
- Автобэкап в `backups/` перед каждой записью
- Скачивание обновлённого `TARGET.xlsx`
- Восстановление из бэкапа

## Типичный сценарий

1. Слева выберите целевой лист (например `OV_LIB` или `Total Yield`).
2. Загрузите Excel/CSV с новыми данными.
3. Проверьте маппинг колонок.
4. Для upsert отметьте ключевые колонки (`Year`+`Month`, `Blend`, `Point` и т.д.).
5. Нажмите **Применить загрузку**.

## Структура

```
TARGET.xlsx          # рабочая книга
start.bat            # запуск на Windows
start.sh             # запуск на Linux/macOS
requirements.txt
app/
  main.py            # FastAPI
  excel_service.py   # логика Excel
  static/            # UI
backups/             # копии перед записью
uploads/             # временные загрузки
```
